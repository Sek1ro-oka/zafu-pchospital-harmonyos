### 导航实现

- `features/home/HomePage.ets` 保留已有首页 / 服务 / 我的三个根内容页，以 `HomeReferenceTabBar` 展示五个导航位置；工作人员中间标签为「工作台」。
- 知识沿用 `NavPathStack` 的已有目的页，返回后恢复之前的 Tab；离开销毁本次问答，符合临时会话约定。五个导航位置不代表五个独立页面均已完工。
- 活动尚未接入，点击给出提示，不切换到虚构列表。首页搜索为打开现有知识问答的入口，并非已实现全局搜索结果页。
- 首页客户进度仍从本人报修接口加载；工作人员不请求或显示客户进度区，审核入口仍按服务器权限展示。
- 主视觉为静态插画，不代表设备已健康或维修已完成；未复制会员活动文案、消息角标、购物内容或社交功能。
- 首页专用视觉组件与 SVG 位于 `features/home/HomeReferenceVisuals.ets` 和 `resources/base/media/home_*.svg`，未修改共享主题或其他业务页。

### 设备卡数据来源说明

- 服务 tab「我的设备」**不是独立的设备绑定接口**：从客户最近 20 条本人报修单（`RepairOrderService.listMine`，服务端按令牌判定归属）的 `deviceModel` 字段派生去重，每个机型取最近一张单展示状态 chip（按机型合并不代表独立物理设备）；点击进对应报修单详情。
- 我的 tab 统计行的计数同样来自本人报修单最近一页（每页 20 条）；后端把分页总数放在信封 meta 里、客户端暂未取到，界面如实标注统计口径。
