# 游客访问与登录入口

App 首次启动没有会话时进入游客首页；服务介绍与公开指南可浏览。客户报修/进度、AI 问诊、我的，以及工作人员业务继续使用原生 Bearer 鉴权，不新增游客模型会话。

## App 行为

- 默认地址 `https://harmony-api.pczafu.cn`；已有自定义地址保留，可在登录页「连接设置」修改。
- 受保护操作记录目标，压入登录目的页；客户/工作人员身份和权限仍取服务端。
- 登录成功弹出登录页并续接目标；游客报修意图在工作人员登录后转向工作人员列表。
- 取消登录或系统返回清除该意图，保留原公共页面；登录请求期间阻止返回，防止迟到响应继续导航。
- 「我的」游客触发登录，成功后显示个人页。退出清栈、清身份、回游客首页。
- 已有会话启动向服务器确认；失效清除令牌，网络不可达保留令牌并以游客浏览。业务接口发现失效时清栈并打开登录，取消后仍可浏览首页。
- 首页/服务的私人数据只在已验证登录后加载；请求代次防止退出或切换账号后的旧数据/错误回写新会话。

## 新增只读 API

`GET /api/v1/public/knowledge/guides` 无需令牌，返回标准成功信封：

```json
{ "guides": [{ "id": "kch_…", "title": "指南标题", "revision": "快照提交" }] }
```

`GET /api/v1/public/knowledge/guides?id=kch_…` 返回同文档的章节：

```json
{ "title": "指南标题", "revision": "快照提交", "sections": [{ "title": "章节", "content": "真实 Markdown 原文" }] }
```

只从已加载索引中选择 **origin=snapshot 且 visibility=PUBLIC** 的文档；目录按来源路径去重，详情按行号排序。内部资料、内部来源（即使错误标为公开）、数据库案例、任意文件路径及未知 ID 均不提供；详情返回 404 `KNOWLEDGE_SOURCE_NOT_FOUND`。索引缺失沿用索引不可用错误，不返回伪造指南。

此端点不查询数据库、不调用 AI 或向量接口，也不放开原 `/knowledge/chat`、检索、引用、案例或维修端点。当前页面为公开目录、标题筛选及原文阅读，尚非完整故障分类知识首页；登录用户的内部案例继续走已有授权入口。
